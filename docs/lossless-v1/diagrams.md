# Diagrams

Open the HTML files in a browser. They are self-contained. The graph JSON is the source. Render with Sylph glowmotion `layout.py` if you need to change a label.

- `cryptoball-v1-architecture.html` — principal vault, harvest check, Switchboard draw.
- `tokenomics-architecture.html` — 90/10 harvest split, burn or treasury, campaign lock.
- `gamification-architecture.html` — campaign pick, points, public settlement.

Rendered HTML is committed beside this file.
